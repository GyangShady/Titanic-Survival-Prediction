# Titanic Survival Prediction 🚢

A machine learning project developed to predict whether a passenger survived the Titanic disaster using passenger information such as age, gender, passenger class, family size, ticket information, and fare.

## Project Overview

This project explores the Titanic dataset and applies supervised machine learning classification techniques to predict passenger survival.

The objective was to investigate survival patterns, engineer meaningful features, compare classification models, and generate predictions for Kaggle's Titanic competition.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook / Kaggle Notebooks

## Methodology

1. Exploratory Data Analysis (EDA)
2. Data cleaning and missing-value handling
3. Feature engineering
4. Numerical and categorical preprocessing
5. Model development and comparison
6. Stratified 5-fold cross-validation
7. Prediction generation and Kaggle submission

## Models Evaluated

- Logistic Regression
- Random Forest Classifier
- Gradient Boosting Classifier

Random Forest and Gradient Boosting achieved approximately 83.84% mean cross-validation accuracy in the initial model comparison.

A feature-selection experiment subsequently achieved approximately 84.06% validation accuracy.

## Kaggle Competition Result

**Competition:** Titanic - Machine Learning from Disaster

**Leaderboard Score:** 0.77751

The leaderboard score represents the model's performance on Kaggle's unseen test data.

## Current Status

The project has a completed baseline submission. Further improvements, feature experimentation, and model optimisation are planned.
